# ลอยกระทงออนไลน์ ๓มิติ (Loy Krathong 3D Online)

เว็บแอปเกม 3D จำลองเทศกาลลอยกระทงและงานวัดไทยยามค่ำคืน พัฒนาด้วย **Three.js + Vite + Vanilla JavaScript** แบบ **100% Procedural Geometry + PBR Material** (ไม่มีโมเดล 3D ภายนอก ทำให้โหลดไวมากและลื่นไหล 60 FPS)

---

## 🌟 ฟีเจอร์หลัก (Key Features)

### 1. บรรยากาศและภาพ (Stylized Night Atmosphere & Visuals)
- **แสงเงาและ Post-Processing:** ใช้ `UnrealBloomPass` มอบแสงเรืองรองอบอุ่นให้กับเปลวเทียน, โคมลอยยี่เป็ง, ไฟราวงานวัด และสะเก็ดพลุ
- **ผิวน้ำสะท้อนแสง (Reflective Dynamic River):** คลื่นแม่น้ำคำนวณด้วยฟังก์ชันคลื่นสมูท ปรับความสูงและ Normal Map แบบ Real-time พร้อมผงประกายแสงระยิบระยับ (Water Glimmers)
- **ดวงจันทร์วันเพ็ญ ๑๕ ค่ำ:** พระจันทร์สีนวลพร้อมวงรัศมีแสงสีทอง (Corona Glow) สาดส่องแสงลงสู่แม่น้ำ

### 2. ระบบเสียงดนตรีสังเคราะห์ (Web Audio API Synthesizer)
- **สังเคราะห์เพลงรำวงวันลอยกระทงสด:** เสียงเครื่องดนตรีระนาดเอก (Ranat Mallet), เสียงฉิ่ง-ฉับ (Open Chime / Damped Clack), เสียงกลองรำวง/โทน-รำมะนา (Klong Ramwong), และเสียงคอร์ดคลอ
- **เสียงเอฟเฟกต์พลุระเบิด:** เสียงหวีดของจรวดพุ่งขึ้นฟ้า + เสียงระเบิดทุ้มก้อง (Sub-bass boom) + เสียงแตกประทัดเปรี๊ยะๆ (Crackle pops)
- **เสียงบรรยากาศสายน้ำ:** เสียงน้ำไหลเบาๆ ผ่อนคลาย
- เริ่มบรรเลงอัตโนมัติเมื่อผู้ใช้แตะหน้าจอครั้งแรก (สอดคล้องกับ Autoplay Policy ของเบราว์เซอร์) พร้อมปุ่มเปิด/ปิดเสียงที่ UI

### 3. โซนท่าน้ำลอยกระทง (Pier & Floating Krathongs)
- **สะพานไม้ยื่นลงน้ำ:** โครงสร้างไม้สักพร้อมโคมไฟโบราณและบันไดลงน้ำ
- **กระทง ๔ แบบ:**
  1. *ใบตองวิจิตร* (Traditional Banana Leaf)
  2. *บัวสวรรค์* (Sacred Lotus Bloom)
  3. *สุพรรณหงส์ทองคำ* (Royal Golden Swan)
  4. *บุปผาสวรรค์* (Eco Floral Basket)
- **ระบบปล่อยกระทง:** ผู้เล่นพิมพ์ชื่อและคำอธิษฐาน มีป้ายชื่อลอยเหนือกระทง เมื่อกดปล่อยกระทงจะลอยลงสู่แม่น้ำและโคลงเคลงตามยอดคลื่นอย่างสมจริงด้วยฟังก์ชัน `getWaterHeight` & `getWaterSlope`
- **กระทง NPC ลอยวนลูป:** มีกระทง NPC ลอยอยู่ในแม่น้ำ 28 ลำ มีชื่อและคำอธิษฐานหลากหลาย เมื่อลอยพ้นขอบน้ำจะวนกลับไปต้นน้ำโดยอัตโนมัติ (Object Pooling) ไม่กินแรม

### 4. ท้องฟ้าและพลุ (Sky Lanterns & Fireworks)
- **โคมยี่เป็ง 180 ดวง:** ใช้ `InstancedMesh` ร่วมกับ Object Pooling ลอยขึ้นฟ้าอย่างนุ่มนวลและส่ายตามแรงลมเรื่อยๆ ใน Draw Call เดียว รันได้ 60 FPS
- **ระบบจุดพลุระเบิด Particle:** คลิกที่ท้องฟ้าจุดไหนก็ได้ หรือกดปุ่ม "จุดพลุ" จรวดจะพุ่งขึ้นและแตกเป็นสะเก็ดแสง 140 อนุภาคกระจายตัวรอบทิศทาง พร้อมแสงแฟลชสว่างวาบสะท้อนผิวน้ำและเสียงสังเคราะห์สมจริง

### 5. โซนงานวัด & นางนพมาศ ๘ คน (Temple Fair & 8 Nang Noppamas)
- **เวทีประกวดนางนพมาศ:** กว้าง 26 เมตร ปูพรมแดง ซุ้มยอดจั่วลายไทย พานพุ่มดอกไม้ทอง และสปอตไลท์ 4 ตัวส่ายสลับแสงสี
- **นางนพมาศ 8 คน สวมชุดไทยพระราชนิยมครบ 8 แบบ:**
  1. *ชุดไทยเรือนต้น* (สีชมพูกลีบบัว)
  2. *ชุดไทยจิตรลดา* (สีฟ้าคราม)
  3. *ชุดไทยอมรินทร์* (สีเขียวมรกตยกทอง)
  4. *ชุดไทยบรมพิมาน* (สีงาช้างประกายทอง)
  5. *ชุดไทยจักรี* (สไบทองคำจีบเฉียง)
  6. *ชุดไทยจักรพรรดิ* (สไบสองชั้นปักดิ้นทองสีแดงทับทิม)
  7. *ชุดไทยดุสิต* (คอยูปักเลื่อมสีน้ำเงินไพลิน)
  8. *ชุดไทยศิวาลัย* (สีม่วงกลีบมะเดื่อห่มสไบทอง)
- **Animation นุ่มนวล:** ท่าพนมมือไหว้ย่อตัวและโยกตัวตามจังหวะเพลง โดยใช้ `Math.sin(time * 1.3 + phase)` แยก Phase แต่ละคน 45 องศา ทำให้เคลื่อนไหวเป็นระลอกคลื่นนุ่มนวลเป็นธรรมชาติ ไม่แข็งทื่อเป็นหุ่นยนต์
- **ซุ้มขายอาหารงานวัด 4 ซุ้ม:** ลูกชิ้นปิ้ง & หมูปิ้ง, ขนมไทย & สายไหม, น้ำสมุนไพร & มะพร้าวสด, ผัดไทย & หอยทอด พร้อมไฟราวงานวัด 48 ดวง
- **เจดีย์ทรายมณีโชติ:** เจดีย์ทราย 4 ชั้น ปักธงทิวหลากสี 38 ผืน และพวงมาลัยดอกดาวเรือง

### 6. การควบคุมและ UI (Controls & Camera)
- **OrbitControls:** หมุนซูมดูรอบฉากได้อย่างอิสระ
- **ปุ่มวาร์ปกล้อง:** ท่าน้ำลอยกระทง, เวทีนางนพมาศ, เจดีย์ทราย & ซุ้มวัด, มุมสูง 360°
- **ปุ่มติดตามกระทง:** ล็อคกล้องติดตามกระทงของผู้เล่นลอยไปตามน้ำ
- **กล่องควบคุมแบบ Glassmorphism:** สวยงาม เรียบหรู ย่อ/ขยายได้เพื่อไม่ให้บังทัศนียภาพ

## 🚀 วิธีการรันโปรเจกต์ (How to Run)

```bash
# 1. ติดตั้ง Dependencies (หากยังไม่ได้ติดตั้ง)
npm install

# 2. เริ่มต้น Development Server
npm run dev

# หรือ Preview Production Build
npm run build
npm run preview
```
เปิดเบราว์เซอร์ที่ `http://localhost:3000` (หรือตามพอร์ตที่ Vite แสดง)
